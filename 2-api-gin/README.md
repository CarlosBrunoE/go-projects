
# 2 Go API with Gin

A simple API with Gin. Based in https://go.dev/doc/tutorial/web-service-gin#prerequisites

## Getting Started

### Prerequisites

Make sure you have Go installed on your machine. You can download it from [https://golang.org/dl/](https://golang.org/dl/).

### How to run it

```bash
go run .
```

```bash
curl http://localhost:8080/albums
```
